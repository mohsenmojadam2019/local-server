# Release notes — 0.1.0

Initial GodControl remote MCP release candidate.

- Added OAuth-scoped public MCP hub.
- Added outbound-only WebSocket device agent.
- Added path and executable allowlists.
- Added 15 reviewable tools for profile, devices, files, Git, system information, and controlled processes.
- Added domain-verification route, public policy pages, audit metadata, and duplicate-call protection.
