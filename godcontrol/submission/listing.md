# GodControl listing draft

**Name:** GodControl

**Short description:** Securely work with files, Git, and approved processes on computers you enroll.

**Long description:** GodControl connects ChatGPT and Codex to computers you explicitly enroll. It provides a bounded set of file, Git, system, and process tools through a secure remote MCP hub. Devices connect outbound to the hub, so users do not open local inbound ports. OAuth scopes and per-device policy restrict what each connection can read or change.
